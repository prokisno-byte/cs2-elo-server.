# CS2 ELO Server — бэкенд

Backend для сайта: регистрация игроков, команды по приглашениям, ЕЛО-система,
лидерборд, и начисление ЕЛО из реальных матчей CS2 через официальный
механизм **Game State Integration (GSI)**.

## Почему именно так

У Valve нет публичного API "дай мне историю матчей MM/Premier игрока".
Единственный официальный способ получить результат конкретного матча —
GSI: сама игра CS2 отправляет live-данные матча на URL, который игрок один
раз прописывает в конфиг-файле у себя в игре. Поэтому:

1. Игрок регистрируется на сайте → получает личный `gsi_token`.
2. Игрок скачивает свой персональный `.cfg` (эндпоинт `GET /api/gsi/config`,
   нужен токен авторизации) и кладёт файл в папку
   `.../Counter-Strike Global Offensive/game/csgo/cfg/` (папка та же и в CS2).
3. Пока запущен CS2, игра сама шлёт JSON на ваш сервер при каждом матче.
4. Сервер видит переход в `gameover`, сравнивает счёт команды игрока со
   счётом соперника → win/loss → пересчитывает ЕЛО.

⚠️ Важно: строка `map.mode`, которую CS2 присылает для Premier/Competitive,
менялась между обновлениями игры. Перед продакшеном залогируйте пару
реальных payload'ов (`console.log(req.body.map)` в `routes/gsi.js`) и
сверьте/поправьте `MODE_MAP`.

## Запуск локально

```bash
npm install
cp .env.example .env
npm start
```

Сервер поднимется на `http://localhost:3000`. Данные хранятся в
`data.db` (SQLite-файл, ничего дополнительно ставить не нужно).

## Основные эндпоинты

- `POST /api/auth/register` `{username, password}`
- `POST /api/auth/login` `{username, password}` → `{token}`
- `GET  /api/auth/me` (нужен `Authorization: Bearer <token>`)
- `POST /api/teams` `{name}` — создать команду
- `GET  /api/teams/:id` — состав команды + средний ЕЛО
- `POST /api/teams/:id/invite` `{username}` — пригласить (только владелец)
- `GET  /api/teams/invites/mine` — мои входящие приглашения
- `POST /api/teams/invites/:inviteId/respond` `{accept: true|false}`
- `GET  /api/leaderboard/players` — топ игроков по ЕЛО
- `GET  /api/leaderboard/teams` — топ команд по среднему ЕЛО
- `GET  /api/gsi/config` — скачать личный `.cfg` для CS2
- `POST /api/gsi/:token` — вызывается самой игрой, руками не дёргать

## Бесплатный деплой без рекламы

Рекомендую **Render.com** (free web service tier) или **Railway** —
у обоих есть бесплатный тариф, никакой рекламы на ваш домен они не
добавляют, только собственные ограничения (сервис "засыпает" при
простое на бесплатном тарифе Render — это нормально для MVP).

1. Залейте эту папку в GitHub-репозиторий.
2. На Render: New → Web Service → подключить репозиторий →
   Build command: `npm install`, Start command: `npm start`.
3. В Environment добавьте переменные из `.env.example`
   (обязательно `PUBLIC_URL` = ваш реальный адрес на Render, он нужен,
   чтобы генерировать правильный `.cfg` для GSI).
4. SQLite-файл `data.db` на бесплатных тарифах может очищаться при
   передеплое — для долгосрочного продакшена стоит переехать на
   бесплатный Postgres (Supabase/Neon), но для MVP и тестов SQLite ок.
